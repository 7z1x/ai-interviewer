# Architecture Decision Records

Folder ini menyimpan keputusan teknis yang sulit dibalik atau memengaruhi beberapa komponen.

Setiap ADR berisi status, context, decision, consequences, dan hal yang perlu diverifikasi. Perubahan keputusan dibuat melalui ADR baru yang menandai ADR lama sebagai superseded; jangan menulis ulang sejarah keputusan.
