# Stage 7 — Final Report

## Scope

Hasilkan report dari evaluation yang sudah tervalidasi.

## Deliverables

- Numeric aggregate dihitung oleh kode.
- Model hanya merangkum data tervalidasi.
- Provenance question/answer/evaluation IDs.
- Report status `complete` atau `incomplete`, versioned regenerate, serta JSON export.
- Tests untuk aggregate, missing evaluation, provenance, idempotency, dan recovery.

## Gate

Semua angka dan quote dapat ditelusuri; report incomplete tidak ditampilkan sebagai final; report dapat dibuka lagi setelah restart.
