# Stage 11 — Optional Avatar

## Scope

Avatar hanya ditambahkan setelah audit provider dan persetujuan pengguna.

## Deliverables

- ADR provider berdasarkan pricing/current terms, retention, biometric/privacy, browser support, dan fallback.
- Adapter terisolasi, toggle, consent/privacy notice, static fallback, dan sinkronisasi audio bila relevan.

## Gate

Text/voice tetap bekerja tanpa avatar; kegagalan avatar terisolasi; consent terlihat; klaim biaya dan capability berasal dari sumber resmi terkini.
