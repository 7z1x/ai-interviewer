# Stage 8 — Frontend MVP

## Scope

Buat UI Home, Setup, Interview Room, dan Result Page di atas API yang sudah terverifikasi.

## Deliverables

- Typed API client dan state loading/empty/error/retry/disabled.
- Pencegahan double submit, responsive layout, keyboard access, dan label/form semantics.
- Tidak menyimpan CV, credential, atau owner secret di localStorage.
- Component tests dan E2E happy path dengan stub.

## Gate

Alur setup → interview → report berhasil; refresh tidak kehilangan session; double click tidak menggandakan data; lint, typecheck, test, build, dan runtime route check lulus.
